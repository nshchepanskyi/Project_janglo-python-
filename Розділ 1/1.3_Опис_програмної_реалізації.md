# 1.3. Опис програмної реалізації

Django-проєкт: `Python_Djanglo/` — `config/` (налаштування) + застосунок `hotel`.
Серверний рендеринг (MVT): моделі → в’юхи → шаблони.

## Моделі (`hotel/models.py`) — порт `hotel_data.py`

| Клас Flet | Модель Django | Поля / особливості |
|---|---|---|
| `Room` | `Room` | `number` unique, `room_type` (Single/Double/Suite), `price` Decimal, `status` (Available/Occupied/Cleaning/Maintenance); `clean()` забороняє від’ємну ціну |
| `Guest` | `Guest` | `name`, `phone` (з кодом країни, напр. `+380…`), `email` |
| `Reservation` | `Reservation` | FK `guest` (CASCADE), FK `room` (PROTECT); `check_in/out` DateField; `status`; `clean()` — `check_out > check_in`; властивості `nights`, `amount = price × nights` |
| `ServiceOrder` | `ServiceOrder` | `service_name`, `service_price`, `quantity`, `total` (авто в `save()`), `timestamp` (auto), `status` |
| `USERS`/`auth.py` | штатний `User` | хешовані паролі, `create_user` / `authenticate` |

Бізнес-функції — прямий порт з `hotel_data.py`:
`calc_reservation_revenue()`, `calc_service_revenue()`, `calc_total_revenue()`,
`get_occupancy_rate()`, `get_services_summary()`, `arrivals_count()`.
`SERVICES_CATALOG` (13 послуг з цінами) перенесено без змін.

## В’юхи (`hotel/views.py`) — порт `views/*.py`

| Flet-в’юха | Django-в’юха | Маршрут |
|---|---|---|
| `login_view` / `register_view` | `login_view` / `register_view` (+`logout_view`) | `/login/`, `/register/`, `/logout/` |
| `dashboard_view` | `dashboard_view` (KPI, останні 6 бронювань, сітка номерів, топ-5 послуг) | `/dashboard/` |
| `rooms_view` | `rooms_view` (`action=add/delete/status`) | `/rooms/` |
| `reservations_view` | `reservations_view` (`action=create/status`; синхронізація статусу номера) | `/reservations/` |
| `guests_view` | `guests_view` (`?q=` пошук) | `/guests/` |
| `services_view` | `services_view` (`action=order/status`; чекбокси + `qty_<name>`) | `/services/` |
| перемикачі `l10n.toggle_lang` / `theme.toggle` | `toggle_lang` / `toggle_theme` (сесії `lang`, `theme`) | `/lang/`, `/theme/` |

Ключові рішення:

- **Бронювання:** гість створюється при кожному бронюванні (як у Flet —
  `create_guest` + `create_reservation`); номер мусить бути `Available`,
  після успіху стає `Occupied`. `Checked-Out` повертає номер в `Available`.
- **Номери:** видалення заборонено, якщо є хоч одне бронювання
  (`Reservation.objects.filter(room=...).exists()`) або статус ≠ `Available` —
  точний порт правила з `rooms.py`.
- **Автентифікація:** вхід за юзернеймом **або** email (порт `login_user`);
  валідація реєстрації 1-в-1 з `auth.py` (≥3 / ≥6 / email-формат / унікальність).
- **Доступи:** усі сторінки, крім login/register, під `@login_required`.

## Шаблони, i18n, тема

- `hotel/templates/hotel/`: `base.html` (сайдбар + топбар — заміна
  `components/navbar.py`, `topbar.py`), `dashboard/rooms/reservations/guests/services.html`,
  `login/register.html`.
- `l10n.py` скопійовано з Flet-версії; мова зберігається в сесії,
  тег `{% tr "Ключ" %}` (`templatetags/tr_tags.py` + `context_processors.ui_prefs`).
- Тема — сесія `theme` + CSS-змінні у `static/hotel/style.css`
  (порт `theme.py`: `_LIGHT`/`_DARK` → `:root` / `[data-theme="dark"]`).
- Адмінка: `hotel/admin.py` (Room/Guest/Reservation/ServiceOrder) — бонус
  Django-версії, у Flet аналога не було.
